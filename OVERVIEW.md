A workspace sidebar for running Paseo on several hosts. It looks and sorts like the built-in list, but keeps each host's projects and workspaces together under its own heading.

Choose **Lucid sidebar** under Settings > Sidebar > Sidebar view; choose the default view to switch back. Requires Paseo 0.16.1 or later.

- **Hosts together.** Each host gets a foldable heading with a guide line in its color, this device's host first. Turn it off with Show > Host.
- **Project tags.** Every row names its project in the project's color. Projects with no workspaces stay hidden.
- **Fold all.** One button folds or unfolds every host, project and status group.
- **Your look.** A settings page (Settings > Plugins > Lucid sidebar, or All settings in the sidebar menu) sets color presets, density, tag style, guide lines and time format, a color and icon for each host, and a color for each project, with a live preview of your sidebar beside the options.
- Everything else works like the built-in list: grouping by project or status, pinned workspaces, the display menu and row actions.

The plugin reads workspace data from your connected hosts and asks the local daemon which host is this device. Nothing leaves your machines. Display preferences are stored on this device.

Rows cannot be dragged, project icons show as colored initials, and Cmd or Ctrl plus a number follows the built-in list's order.
